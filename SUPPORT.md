# Support and feedback

## Report a GUI bug

Use the [GUI issue form](https://github.com/CommandCodeAI/gui/issues/new/choose)
and include:

- Command Code GUI version
- Operating system and architecture
- Clear reproduction steps
- What you expected and what happened
- A screenshot or short recording when useful

Before attaching logs, remove API keys, access tokens, email addresses, private
file paths, `.env` values, and project source code.

## Product feedback

Feature requests and workflow feedback are welcome through
[GitHub Issues](https://github.com/CommandCodeAI/gui/issues/new/choose) or the
[Command Code Discord](https://commandcode.ai/discord).

## Installation help

Follow [INSTALL.md](INSTALL.md) for macOS installation, digest verification,
and unsigned-preview troubleshooting. Linux and Windows builds are coming
soon.

Security vulnerabilities must be reported privately using
[SECURITY.md](SECURITY.md).
