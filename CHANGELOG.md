# Changelog

## 0.1.0 — 2026-07-30

First public preview of Command Code GUI.

- Added project and chat management
- Added streaming agent conversations and task progress
- Added plan review and iterative feedback
- Added file browsing and line-level diff review
- Added Git changes, commit, and push workflows
- Added an integrated project terminal
- Added model, permission, appearance, and shortcut settings

This preview includes macOS and Linux builds. Windows support, trusted
code-signing, notarization, and automatic updates are coming next.
